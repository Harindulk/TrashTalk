# Contract v2: wire it in the Editor

The developer wants the game wired in the Unity Editor (scene, prefabs, Inspector references) with **as little code as possible**. Today everything is built from code at runtime (Art.Make, TrashCan.Create, LevelBuilder, UI built in code, Bootstrap). We convert to:

- **One scene** `Assets/Scenes/Game.unity` holding camera, systems, UI canvas, EventSystem, menu backdrop.
- **Prefabs** for every object, with sprites/clips/fonts/child refs assigned in the Inspector.
- **Level prefabs** `Assets/Prefabs/Levels/Level01.prefab … Level10.prefab` that a designer edits in the Scene view.
- Runtime scripts keep only behaviour. Construction code goes away.

How we get there without hand-clicking: each area writes a **one-off Editor baker** `Assets/Editor/Bake/Bake<Area>.cs` with `public static string Run()` that builds its prefabs/scene in edit mode (same look and sizes as today's runtime code) and saves them. The lead runs the bakers in order (Feel → Rocket → Cans → Levels → Scene), checks the result in the Editor, then **deletes Assets/Editor/Bake/**. So bakers may be quick-and-dirty; the runtime scripts must be clean and small.

## Rules
- Runtime scripts: `[SerializeField]` or public fields for every reference (child transforms, SpriteRenderers, sprites, clips, prefabs, Text). No `new GameObject` for visuals, no `AddComponent` for visuals, no `Art.Make`, no `Resources.Load`, no `Shader.Find`, no procedural textures/audio at runtime. Instantiate prefabs instead. Tuning numbers stay public fields with defaults.
- Keep behaviour/feel identical to today (read the current code first; it's the reference). Keep the same static/public APIs listed below unless this file says otherwise.
- Bakers: Editor-only (`using UnityEditor;`), build GameObjects, assign assets via `AssetDatabase.LoadAssetAtPath<T>(path)`, nest other areas' prefabs with `PrefabUtility.InstantiatePrefab(AssetDatabase.LoadAssetAtPath<GameObject>(path))` so links stay live, save with `PrefabUtility.SaveAsPrefabAsset(go, path)` then `Object.DestroyImmediate(go)`. Create folders with `AssetDatabase.CreateFolder` if missing. Idempotent (overwrite). Return a short log string. Set import settings you need (e.g. `TextureImporter.wrapMode = Repeat`, `spriteMeshType = FullRect` for tiled sprites) inside your baker.
- Do NOT run Unity or `unity` CLI. Only edit your own files. Other agents are editing theirs right now.
- Unity 6000.6 APIs: `Rigidbody2D.linearVelocity`, `FindAnyObjectByType`, `FindObjectsByType<T>()` (no sort mode arg), `ContactFilter2D.noFilter`.
